# AI-Powered Sales Intelligence

## Overview
A sales analytics project combining machine learning-based revenue forecasting with a Power BI dashboard.

## Key Features
- Actual vs. predicted revenue analysis
- Future revenue forecast visualization
- Revenue and model-error KPIs
- Daily sales trend analysis

## Tools & Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Power BI

## Project Files
- `AI_Sales_Forecasting.ipynb` — sales forecasting notebook
- `Machine learning-based sales forecasting and Power BI dashboard.pbix` — Power BI report
- `Screenshot.png` — dashboard image 

## Learning Outcomes
Practiced connecting machine learning predictions with business intelligence reporting and visualizing forecasting results.
